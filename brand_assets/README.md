# Brand Assets

Hier gehören die verbindlichen Marken-Assets von Tugässer Bräu hinein:
Logo (SVG/PNG), Farbschema, Schriftarten, Styleguide, freigegebene Fotos.

**Solange dieser Ordner leer ist, sind die Werte in `tailwind.config.js`
provisorisch** — abgetastet aus `images/tugaesser-rathaus-hero-1600x900.png`.
Sobald echte Assets vorliegen: Farben und Fonts in `tailwind.config.js`
ersetzen und diesen Hinweis entfernen.
